## 2. P1 · 鲜活度与素材生产（1~2 周）——先把"丑/僵/单调"解决

### 2.1 真动作系统（替换程序化占位）
- 接入 `@pixiv/three-vrm-animation`，支持 **.vrma** 动作文件加载与循环/混合
- 动作包本地化到 `frontend/public/motions/`（VRoid 官方 7 个免费 VRMA 起步；Mixamo 动作经离线重定向脚本转 VRMA，一次转换全角色通用）
- **VMD 舞蹈播放器**（mmd-parser + 骨骼名映射，参考 lobe-vidol 实现，Apache-2.0）：MMD 社区海量成品舞（含镜头/节拍），先内置 2~3 支授权明确的舞蹈
- 动作状态机：idle ⇄ 说话手势 ⇄ 情绪动作 ⇄ 舞蹈，带 0.3s 交叉淡入（消除"瞬移感"）
- 验收：跳舞观感为真人 mocap 级；动作切换无跳变；任意 VRM 模板通用

### 2.2 AI 背景生成 + 背景库
- 后端 `POST /api/v1/assets/background`：一句话描述 → 图像模型出图 → MinIO/本地存储 → 背景库
- 图像适配器：`IMAGE_MODEL=gpt-image-2`（.env 可配），未开通时自动降级 `linkyun-image-default`（实测 11s/1024²可用）
- 聊天页背景面板加「AI 生成」标签页：描述 → 生成 → 预览 → 应用/入库；背景库按角色/全局管理
- 验收：30s 内从一句话得到可用背景；背景库可增删复用

### 2.3 模板库与打断收尾

- 打断自适应：通话前 1s 采样环境底噪自动校准 BARGE_IN 阈值（消除设备差异）

## 3. P2 · AI 形象工厂（2~4 周）——"给图片/一句话 → 自己的虚拟偶像"

| 步骤 | 技术 | 时长/成本（单角色） |
| --- | --- | --- |
| 1. 立绘生成 | gpt-image-2：角色设定→正面全身立绘（A-pose、纯色底、全身入框 prompt 模板）；或用户直接上传图片 | ~10-30s · 1~3 张 |
| 2. 图生 3D | Meshy Image-to-3D（含贴图 30 credits）或 Tripo image_to_model；**二选一做主链路，另一家做降级** | 1~3 分钟 |
| 3. 自动绑骨 | Meshy Rigging API（GLB 直出，<30s，5 credits）或 Tripo animate_rig（mixamo 骨架） | <1 分钟 |
| 4. 质量门控 | 三视图预览（three.js 转台）→ 用户确认 / 重roll（最多 3 次）/ 回退模板 | 用户决策 |
| 5. 入库上台 | `avatar_asset` 状态机（pending→generating→preview→confirmed）；GLB 经 mixamo 骨架直接驱动现有动作库 | 即时 |

- 端到端目标：**5 分钟内**从一句话/一张图得到能聊天、能做动作的专属 3D 角色
- 单角色生成成本 ≈ Meshy 35~40 credits + 1~3 张图（以网关计费为准），失败重roll 计入预算上限
- 口型/表情：生成模型无 blendshape → 先用「头部骨骼点头 + 音频驱动头部微动」过渡，VRM 化补全表情留 P4
- 风险：脸/手细节方差大 → 立绘先确认再 3D 化；动漫风格优先（生成质量最稳）；写实风格二期
- Agent 建角流程升级：描述 → 人设 + 立绘 + 3D 模型一条龙，全程可视进度（WS 推送任务状态）

## 4. P3 · 可玩性系统（4~8 周）——"养成 + 互动"

- **捏脸 traits v1**：模板部件化（发型/发色/瞳色/服装 30~50 件）+ 材质调色；LLM 描述→traits JSON（与 agent-draft 同构）
- **对话式改外观**：聊天指令（"把头发换成银色"）→ traits diff → `avatar.update` 事件（协议 V1.2 已预留）→ 实时重渲染
- **好感度/成长**：互动累计 + 记忆联动（pgvector 已就绪）；等级解锁动作/服装/场景；每日签到剧情
- **舞蹈编排器**：曲目库 + BGM 节拍解析（BPM 对齐动作速度）+ 多段舞蹈串联；观众模式镜头运镜
- **场景包**：背景 + 光照色温 + BGM 三件套一键切换（教室/海边/舞台/雨夜…），AI 可整包生成
- **拍照/分享**：构图卡（角色 pose + 背景 + 滤镜）→ 一键出图分享
- 验收：单角色平均会话时长、次日留存（埋点已在 message.latency_ms 基础上扩展）

## 5. P4 · 成熟化与降本（8 周+）
